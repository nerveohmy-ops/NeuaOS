# Architecture Decision Records

This directory records architectural decisions for NeuaOS.

Each ADR follows a lightweight format:

- **Status** — Proposed, Accepted, Superseded, or Rejected.
- **Context** — the forces at play.
- **Decision** — what was chosen.
- **Consequences** — what becomes easier or harder.
- **Alternatives** — considered options, where useful.

ADRs are immutable once accepted. To change a decision, add a new ADR
that supersedes the old one, and update the old ADR's status.
